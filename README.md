# CardArena

Browser card-game platform — see [card-game.md](card-game.md) for the full product spec.
All ten catalog games are playable against AI bots: **Bhabhi Thulla, Court Piece, 29, Seep, Call Break,
Hokm, Tarneeb, Baloot, Spades and Hearts**. Multiplayer is not built yet (spec §157).

```
frontend/   Angular 20 (standalone components, signals, SCSS)
backend/    FastAPI, SQLAlchemy 2 (async), Alembic, PostgreSQL
```

## Running locally

Requires Node 20+, Python 3.12+ and PostgreSQL.

```bash
# Backend — http://localhost:8000 (Swagger at /docs)
cd backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # set DATABASE_URL and a real JWT_SECRET_KEY
createdb cardarena
alembic upgrade head            # creates tables and seeds games + achievements
uvicorn app.main:app --reload

# Frontend — http://localhost:4200
cd frontend
npm install
npm start                       # proxies /api to :8000 (proxy.conf.json)
```

## Tests

```bash
cd backend && pytest                    # needs a `cardarena_test` database (or set TEST_DATABASE_URL)
cd frontend && npm run test:engines     # Vitest: rules/bot tests for every table game
cd frontend && npm run test:ci          # Karma: Bhabhi Thulla engine + bot tests in headless Chrome
```

## How it fits together

**Game engine is separate from the UI** (spec §140). `frontend/src/app/games/bhabhi-thulla/engine/`
holds the rules, engine and bots as plain TypeScript with no Angular imports. `BhabhiThullaStore`
drives the engine for one table (bots, pacing, turn timer) and components only read its signals.

**AI games run in the browser** (spec §142), so play needs no server round-trips and works for guests.

**The server is still the referee for results.** Decks are shuffled with a seeded PRNG (mulberry32).
When a logged-in player finishes, the client sends only the seed, seats and move list.
`backend/app/games/bhabhi_thulla/engine.py` — a line-for-line port of the TypeScript engine —
replays the game, rejects any illegal move, and computes the finishing order, scores, XP and achievements
itself. `tests/test_engine_parity.py` replays 36 games generated by the TypeScript engine
(`npm run export-replays`) to keep the two engines in lockstep.

Since the browser also plays the bots, a determined cheater could still craft a winning game; the
replay check stops fabricated or illegal results. Full anti-cheat arrives with server-authoritative multiplayer.

**Auth:** short-lived JWT access token kept in memory; rotating refresh token in an HTTP-only cookie
(revoked on logout and on every refresh).

## Adding a game

Every game except Bhabhi Thulla runs on a shared table framework (`frontend/src/app/games/core/`):
an engine implementing `TableGameEngine` (legal actions, `apply`, `pending`/`resolve`, `outcome`), a bot
function, and a `GameDefinition`. The generic screen at `/play/:slug` renders any registered game.

1. Create `games/<name>/` with `<name>.engine.ts`, `.bot.ts`, `.definition.ts`, `.content.ts`, `.test.ts`
   (Court Piece is the smallest reference).
2. Port the engine rules to `backend/app/games/<name>/engine.py` (same RNG order, integers only).
3. Register it in `frontend/src/app/games/registry.ts`, `core/data/games.data.ts` and `backend/app/games/registry.py`.
4. `node scripts/export-replays.mjs <name>` (in `frontend/`), then `pytest tests/test_table_parity.py`.

## Rule notes for the table games

Each game page and in-game rules dialog states the exact rules used. Simplifications worth knowing:
Seep takes one capture combination per play and allows one house per value; Baloot has Sun/Hokm, contracts and
the Baloot bonus but no other projects or doubling; Spades has Nil but no Blind Nil; 29 has no last-trick point
(28 total). Court Piece and Hokm hands end once a team reaches seven tricks.

## Bhabhi Thulla rules implemented

All variants: follow suit if you can; if everyone follows, the trick is discarded and the highest card leads;
otherwise the off-suit card is a **Thulla** — the trick ends and the highest card of the led suit picks everything up.
Empty hands escape; the last player holding cards is the **Bhabhi**.

| Variant | Opening | First trick |
|---|---|---|
| Pakistan (default) | Ace of Spades leads | Free round — off-suit cards are discarded, no pickup |
| India | Ace of Spades leads | Thulla allowed |
| Open start | Random leader, any card | Thulla allowed |

Bot levels: **Easy** (often random), **Normal** (ducks under the high card, dumps high cards when last),
**Hard** (+ tracks voids and known pickups), **Expert** (+ hypergeometric estimate of Thulla risk).

## Status vs. MVP definition of done (spec §149)

Done: Angular app, FastAPI backend, PostgreSQL + migrations, registration/login, homepage, games catalog,
Bhabhi Thulla with tested rules, AI bots, card animations, game result, statistics/XP/achievements/history,
leaderboard, mobile UI (down to 320px), SEO game pages with metadata/JSON-LD, sitemap and robots.txt.

Not yet: production deployment, multiplayer/WebSockets (deliberately deferred per spec §157),
server-side rendering for SEO, real audio assets
(sound effects are synthesized with Web Audio for now).

Before going to production, replace `your-domain.com` in `frontend/public/{robots.txt,sitemap.xml}`,
`frontend/src/index.html` and `environment.prod.ts`, set `ENVIRONMENT=production` (secure cookies)
and a strong `JWT_SECRET_KEY`.
